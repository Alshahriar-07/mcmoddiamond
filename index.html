01 · Feature inventory

BUILT FOR THE RUSH

Two players. Three diamond challenges. A complete in-game flow that keeps the match moving without command lists.

Verified V4 flowEvery feature below is part of the current mod implementation.

01Core

Competitive 1v1 Matches

Two players enter one arena and race through a server-controlled duel. Only match competitors can damage each other while a round is active.

02Core

Three Diamond Challenges

Obtain a diamond, mine two more, then craft a diamond pickaxe. Every round changes the objective and the starting loadout.

03V4 UI

Custom Main Menu

A GUI-driven lobby replaces command lists. Create arenas, browse available players and manage invitations from one interface.

04Arena

Arena Creation

Create and manage an arena from the main menu, then open its lobby to invite a rival and control the start of the match.

05Social

Player Invitations

Invite an available player and accept or decline incoming invitations from the dedicated Invitations screen.

06Live

Live Match Scoreboard

The in-game scoreboard tracks both players, the current round and the active objective as the match unfolds.

07Flow

Automatic Round Progression

The server runs countdowns, restores loadouts, advances rounds and crowns the first player to two round wins.

08Server

Dedicated Server Support

Runs on Fabric dedicated servers. V4’s client handshake opens the menu when the play channel is ready, with /diamondrush on as a recovery command.

02 · Match structure

THREE ROUNDS. ONE WINNER.

Each round tests a different part of the diamond loop. The server resets the arena, inventory and objective between rounds.

Best of threeThe first player to win two rounds takes the match. Round three only happens at 1–1.

01Round
Diamond Rush

First diamond wins.

Be the first player to legitimately obtain one diamond. A valid ore must be mined and the diamond collected—picking up someone else’s drop does not count.

04 · Installation guide

FROM DOWNLOAD TO FIRST MATCH.

Set up the dedicated server first, then install the same V4 build on every participating player’s client. Vanilla clients cannot render the custom interface.

Both sides requiredThe mod belongs on the dedicated server and every participating player’s Fabric client.

REQUIRED SETUP

MinecraftJava Edition 26.2
Fabric Loader0.19.3+
Fabric API0.154.0+26.2
Java25 or newer
Same JAR on both sides. Install Diamond Rush V4 on the dedicated server and on every player’s client. A vanilla client cannot see the Diamond Rush menu or HUD.

INSTALLATION STEPS

  1. 1

    Install Minecraft 26.2

    Set up a Java Edition 26.2 dedicated server.

  2. 2

    Install Fabric Loader

    Install Fabric Loader 0.19.3 or newer for Minecraft 26.2.

  3. 3

    Add Fabric API

    Use Fabric API 0.154.0+26.2 or the matching 26.2 build.

  4. 4

    Download Diamond Rush V4

    Get the official Diamond-Rush-1v1-v4.jar from the release section below.

  5. 5

    Place both JARs in mods

    Put Fabric API and the Diamond Rush V4 JAR in the server’s mods/ folder.

  6. 6

    Start and equip clients

    Start the server, then install the same V4 JAR and Fabric API on every participating player’s client before they join.

  1. 1

    Install Minecraft 26.2

    Use Minecraft Java Edition 26.2 on your player client.

  2. 2

    Install Fabric Loader

    Install Fabric Loader 0.19.3 or newer and create the 26.2 profile.

  3. 3

    Add Fabric API

    Install Fabric API 0.154.0+26.2 or the matching 26.2 build.

  4. 4

    Download Diamond Rush V4

    Download the official V4 JAR from the release panel below.

  5. 5

    Place both JARs in mods

    Put Fabric API and Diamond Rush V4 in your client’s mods/ folder, then launch the Fabric 26.2 profile.

  6. 6

    Join the server

    The menu opens automatically for compatible clients. If it is closed, run /diamondrush on.

Java 25+ is required on both server and client.
