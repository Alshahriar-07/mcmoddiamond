Built for a fast duel

Everything a server needs to run short, fair 1v1 matches.

Matchmaking

Join the queue and get paired with another player automatically.

Diamond race

Dig down. The first player to break a diamond ore wins the round.

Best of five

Win three rounds to be crowned tournament champion.

Custom arenas

Set up as many arenas as you like, each with its own player spawns.

Clean resets

Inventory, armor, XP and effects are wiped between rounds.

Saved stats

Player stats, wins and tournament records survive server restarts.

How a match plays out

  1. 1

    Join the queue

    Two players run the join command and get paired.

  2. 2

    Get ready

    Both players enter the arena and confirm they’re ready.

  3. 3

    Mine first

    Break a diamond ore before your opponent does.

  4. 4

    Take the title

    Win three rounds to claim the tournament.

Install

Set it up on the server and on both players’ clients.

MinecraftJava Edition 26.2
Fabric Loader0.20.1
Fabric API0.161.0+26.2
Java25
  1. Install Fabric Loader for Minecraft 26.2 on your server.
  2. Download Fabric API and the Diamond Rush JAR.
  3. Put both JAR files in the server’s mods folder.
  4. Start the server and set up your arenas.
  1. Install Fabric Loader 26.2 on your Minecraft client.
  2. Put Fabric API and the Diamond Rush JAR in your client’s mods folder.
  3. Launch the Fabric 26.2 profile.
  4. Join the server and start competing.

Both players need the mod on their clients to see the match screen and Ready buttons. The same JAR works on client and server.
